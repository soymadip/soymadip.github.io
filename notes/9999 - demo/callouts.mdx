# Callouts

Here is a quick overview of all the callouts (admonitions) perfectly themed to match your color scheme!

:::info Info Callout

This is an **info** callout. It should inherit the `--porto-info` colors!

:::

:::success Success Callout

This is a **success** callout. Perfect for showing things that went well! Inherits `--porto-success`.

:::

:::warning Warning Callout

This is a **warning** callout. Use it for things that the user should be careful about! Inherits `--porto-warning`.

:::

:::danger Danger Callout

This is a **danger** callout. Use it for critical issues! Inherits `--porto-danger`.

:::

:::note Note Callout

This is a **note** callout. It inherits `--porto-secondary`.

:::
