# Unit 2: Subjective Question Bank

Detailed answers to the core subjective questions from Unit 2: Data Mining Introduction. These answers are formulated in a pointed, exam-ready style with practical examples.

## Core Questions and Answers

#### 1. Define Data Mining.
Data Mining is the process of extracting hidden, valid, and actionable patterns from large datasets. It is the "knowledge discovery" phase where intelligent methods are applied to find non-obvious relationships.

**Example:** A retail store analyzing past purchase data to discover that customers who buy beer also tend to buy diapers.

#### 2. What is KDD? Explain the steps of the KDD process briefly.
**KDD (Knowledge Discovery in Databases)** is the overall process of turning raw data into useful knowledge. Data mining is a specific step within this lifecycle.

**Steps:**
1. **Data Cleaning:** Removing noise and inconsistent data.
2. **Data Integration:** Combining multiple data sources.
3. **Data Selection:** Choosing data relevant to the task.
4. **Data Transformation:** Normalizing or aggregating data into mining-ready formats.
5. **Data Mining:** Applying algorithms to extract patterns.
6. **Pattern Evaluation:** Identifying truly interesting patterns.
7. **Knowledge Presentation:** Visualizing and representing the results.

#### 3. Differentiate between Data Mining and Data Warehousing.
| Feature    | Data Warehousing (DW)             | Data Mining (DM)               |
| :--------- | :-------------------------------- | :----------------------------- |
| **Goal**   | To integrate and store data.      | To analyze data for patterns.  |
| **Nature** | A centralized data repository.    | A knowledge discovery process. |
| **Focus**  | Data architecture and management. | Data analysis and algorithms.  |
| **Output** | Organized, historical data.       | Predictions and correlations.  |

#### 4. Discuss the major issues in data mining.
- **Mining Methodology:** Handling noise, incomplete data, and complex data types.
- **Performance:** Ensuring scalability for massive datasets and parallel processing.
- **User Interaction:** Incorporating background knowledge and interactive visualization.
- **Ethics & Privacy:** Protecting personal data and preventing misuse of information.

#### 5. Define data, information, and knowledge.
- **Data:** Raw, unorganized facts (e.g., "100").
- **Information:** Data with context and meaning (e.g., "Daily sales: $100").
- **Knowledge:** Interpreted information that leads to action (e.g., "Sales are low; we need a discount").

#### 6. What is data cleaning?
Data cleaning is the process of removing errors and inconsistencies from data. It involves filling in missing values, smoothing noisy data, and identifying or removing outliers.

**Example:** Correcting a dataset where some ages are listed as negative numbers or are missing entirely.

#### 7. What is data transformation?
Data transformation is the process of changing data into a form suitable for mining.

- **Normalization:** Scaling numbers to a range (e.g., 0 to 1).
- **Aggregation:** Summarizing data (e.g., calculating monthly sales from daily records).

**Example:** Converting a "Date of Birth" column into an "Age" column for easier analysis.

#### 8. What is a data repository? Explain different types.
A **Data Repository** is a centralized location for data storage.
- **Relational Databases:** Structured tables with rows/columns.
- **Data Warehouses:** Integrated historical data for analysis.
- **Transactional Databases:** Optimized for fast, day-to-day operations (OLTP).
- **Object-Oriented Databases:** Stores data as objects (used in specialized apps).

#### 9. What is classification in data mining? What is clustering?
- **Classification:** Predicting a specific class label for new data based on a training set (Supervised Learning). *Example: Marking an email as "Spam" or "Not Spam".*
- **Clustering:** Grouping similar data points together without predefined labels (Unsupervised Learning). *Example: Grouping customers into "High Spenders" and "Budget Shoppers" based on behavior.*

#### 10. What is an association rule?
Association rule mining finds relationships between items in a dataset. It is commonly used for Market Basket Analysis.

**Example:** A rule stating that 70% of people who buy "Coffee" also buy "Sugar."

#### 11. What are outliers?
Outliers are data points that deviate significantly from the rest of the dataset. While often treated as noise, they are critical for detecting anomalies.

**Example:** Detecting a $10,000 transaction on a credit card usually used for small grocery purchases (Fraud Detection).

#### 12. Explain data mining functionalities with examples.
- **Association:** Finding items that go together (e.g., Beer and Diapers).
- **Classification:** Assigning categories (e.g., Classifying a loan as "Safe" or "Risky").
- **Clustering:** Finding natural groups (e.g., Grouping similar news articles).
- **Outlier Analysis:** Finding anomalies (e.g., Identifying network intrusions).

#### 13. Differentiate between descriptive & predictive data mining tasks.
- **Descriptive:** Summarizes the current state of data to find general properties. (e.g., "Which products sell together?").
- **Predictive:** Uses current data to make inferences about future or unknown values. (e.g., "Will this customer churn next month?").

#### 14. Describe various data mining trends.
- **Multimedia Mining:** Analyzing images, video, and audio.
- **Web Mining:** Extracting knowledge from web content and usage.
- **Spatial Mining:** Analyzing geographic and location-based data.
- **Privacy-Preserving Mining:** Developing algorithms that protect sensitive user data.

#### 15. Explain methods of presenting derived models.

- **IF-THEN Rules:** Knowledge is expressed as logical conditions. *Example: IF student_score > 90 THEN grade = 'A'.*
- **Decision Trees:** A flowchart-like structure where nodes represent tests and leaves represent labels. It is highly intuitive for human review.
