## 1. Write about project cycle.

A project cycle refers to the different stages through which a project passes from its beginning to its completion.

### Stages of Project Cycle:

1. **Conceptualization**: In this stage, the project idea is identified and the objectives are decided.

2. **Planning**: The activities, budget, resources, and time required for the project are planned.

3. **Execution**: The project plan is implemented and the actual work is carried out.

4. **Termination**: The project is completed, evaluated, and formally closed.

---

## 2. Define project and project management.

### Project

A project is a planned activity or task undertaken to achieve a specific economic objective within a fixed time and budget.

- **Example:** setting up a factory, starting a business, building a road.

### Project Management

Project management is the process of planning, organizing, controlling, and completing a project efficiently by using available resources like money, labor, and materials.
