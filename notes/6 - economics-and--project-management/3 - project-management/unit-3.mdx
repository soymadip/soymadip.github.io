## 1. What is Gantt chart? State how it helps in project management.

### Gantt Chart

A Gantt chart is a graphical tool used in project management to show the schedule of project activities over a period of time.

- It displays tasks, starting date, ending date, and progress of the project in the form of horizontal bars.
- It helps in planning, scheduling, and monitoring project work easily.

### How It helps in Project Management

1. It helps in planning project activities properly.
2. It shows the starting and ending time of each task.
3. It helps in monitoring the progress of the project.
4. It makes it easier to complete the project on time.
5. It improves coordination among team members.

## 2. What do you mean by PERT and CPM?

### PERT (Program Evaluation and Review Technique)

- PERT is a project management technique used to plan and control projects where the time required for activities is uncertain.
- It helps in estimating the time needed to complete a project.

### CPM (Critical Path Method)

- CPM is a project management technique used to plan and schedule activities in a project.
- It helps in identifying the longest path of activities and completing the project on time.

## 3. Write the difference between PERT and CPM.

| PERT                                                     | CPM                                                      |
| :------------------------------------------------------- | :------------------------------------------------------- |
| PERT stands for Program Evaluation and Review Technique. | CPM stands for Critical Path Method.                     |
| It is used when activity time is uncertain.              | It is used when activity time is fixed and known.        |
| It focuses mainly on time estimation.                    | It focuses on time and cost control.                     |
| It is suitable for research and development projects.    | It is suitable for construction and production projects. |
| PERT uses probability for time estimation.               | CPM uses a fixed time estimate.                          |
