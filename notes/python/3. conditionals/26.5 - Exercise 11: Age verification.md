# Ex: 11 - Age verification

## Problem

You’re building a system to verify user age for access.

- Define `verify_age(age_str)` that accepts a string.
- Convert the string to an integer.
- Return the correct access message using a ternary expression.

## Rules

- Define `verify_age(age_str: str) -> str`.
- Use `int(age_str)` to parse the input.
- Return "Access Granted" if age is 18 or older.
- Otherwise return "Access Denied".
- Only view the solution after trying your best.

```text
Access Granted
```

## Solution

Only view the solution after trying your best.

<details>
<summary>Show solution</summary>

```python
def verify_age(age_str: str) -> str:
    age = int(age_str)
    return "Access Granted" if age >= 18 else "Access Denied"
```

</details>

## Why this pattern works

- `int(age_str)` converts the text to a number.
- The ternary expression returns one of two strings in a single line.
- It is ideal for simple binary choices like access control.

## What to watch for

:::warning
This function assumes valid numeric input. In a real app, validate the text before calling `int()`.
:::

:::tip
Wrap `int()` in `try`/`except ValueError` if user input may be malformed.
:::
