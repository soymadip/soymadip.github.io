# Free dessert offer

What to remember

- Use `if` to test conditions and `return` to exit the function immediately.
- `else` is optional when the `if` branch already returns.
- Keep the returned strings consistent and exact when values are checked later.

## Conditional Return Example

Return a message depending on the bill total.

```python
def get_delivery_offer(bill_amount: float) -> str:
    if bill_amount > 500:
        return "You get a free dessert!"
    return "No free dessert this time."

print(get_delivery_offer(650.0))
print(get_delivery_offer(300.0))
```

## Why This Pattern Works

- `if bill_amount > 500:` runs only when the bill is higher than the threshold.
- `return` stops the function and sends back the message.
- The second branch handles all remaining values.

## Example Output

```text
You get a free dessert!
No free dessert this time.
```

:::note Exact Output
Because this is an exercise note, the returned strings must match the expected result exactly.
:::

:::tip Implementation Tip
In practice, use constants or enums for repeated return strings to avoid typos.
:::
