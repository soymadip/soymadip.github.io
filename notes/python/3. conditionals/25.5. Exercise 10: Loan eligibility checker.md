# Loan eligibility checker

## Problem

You’re building a basic loan eligibility checker for a bank. A customer must meet two conditions to be eligible.

- Define `check_loan_eligibility(age, income)` to return one of three messages.
- Check the age requirement before evaluating income.
- Preserve the correct branch order for eligibility.

## Rules

- Define `check_loan_eligibility(age: int, income: float) -> str`.
- If age is 21 or above and income is 25,000 or above, return "Eligible for loan".
- If age is 21 or above and income is below 25,000, return "Not eligible: Income too low".
- If age is less than 21, return "Not eligible: Age must be 21 or above".
- Only view the solution after trying your best.

```text
Eligible for loan
```

## Solution

Only view the solution after trying your best.

<details>
<summary>Show solution</summary>

```python
def check_loan_eligibility(age: int, income: float) -> str:
    if age >= 21:
        if income >= 25000:
            return "Eligible for loan"
        return "Not eligible: Income too low"
    return "Not eligible: Age must be 21 or above"
```

</details>

## Why nested checks work here

- The outer `if` ensures only eligible ages reach the income branch.
- The inner `if` handles the second rule cleanly.
- The final return covers users too young for the loan.

## Branch Breakdown

- age < 21 → `Not eligible: Age must be 21 or above`
- age >= 21 and income < 25000 → `Not eligible: Income too low`
- age >= 21 and income >= 25000 → `Eligible for loan`

:::tip
When writing conditional rules, name each branch clearly in comments or doc notes to keep the logic readable.
:::
