# Loan eligibility checker

What to remember

- Use nested `if` statements when one condition depends on another.
- Check the age requirement before evaluating income.
- Return exact strings for testable outputs.

## Eligibility Rule Example

```python
def check_loan_eligibility(age: int, income: float) -> str:
    if age >= 21:
        if income >= 25000:
            return "Eligible for loan"
        return "Not eligible: Income too low"
    return "Not eligible: Age must be 21 or above"
```

```python
print(check_loan_eligibility(25, 30000))
```

## Why Nested Checks Work Here

- The outer `if` ensures only eligible ages reach the income branch.
- The inner `if` handles the second rule cleanly.
- The final return covers users too young for the loan.

## Branch Breakdown

- age < 21 → `Not eligible: Age must be 21 or above`
- age >= 21 and income < 25000 → `Not eligible: Income too low`
- age >= 21 and income >= 25000 → `Eligible for loan`

### Example Output

```text
Eligible for loan
```

:::tip
When writing conditional rules, name each branch clearly in comments or doc notes to keep the logic readable.
:::
