# Match-case

What to remember

- `match` evaluates one expression and checks each `case` in order.
- `case _` is the fallback if no other pattern matches.
- Literal string patterns are common for menu items or command values.
- Normalizing text with `.lower().strip()` makes matches more reliable.

## Literal Branch Matching

```python
seat_type = "ac"
match seat_type:
    case "sleeper":
        print("Sleeper - No AC, beds available")
    case "ac":
        print("AC - slslj")
    case "general":
        print("General - You cheap!")
    case "luxary":
        print("Damn!")
    case _:
        print("Unknown")
```

## Output

```text
AC - slslj
```

## Why the Fallback Matters

:::note Fallback Behavior
`case _` runs only after every other `case` fails. This makes it the default branch for unexpected values.
:::

## What This Looks Like in Practice

This pattern is useful when the input can be one of several known values, such as seat types, menu selections, or command keywords. It keeps the branch logic grouped together and avoids repeated comparisons.
