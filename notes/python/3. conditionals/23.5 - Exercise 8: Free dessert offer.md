# Ex: 8 - Free dessert offer

## Problem

You’re designing a billing system for a restaurant. Depending on the total bill amount entered by the customer, they might get a free dessert.

- Define `get_delivery_offer(bill_amount)` to return one of two messages.
- Return the dessert message only when the bill is above the threshold.
- Return the non-dessert message otherwise.

## Rules

- Define `get_delivery_offer(bill_amount: float) -> str`.
- If the bill amount is greater than 500, return "You get a free dessert!".
- Otherwise return "No free dessert this time.".
- Only view the solution after trying your best.

## Expected output

```text
You get a free dessert!
No free dessert this time.
```

## Solution

Only view the solution after trying your best.

<details>
<summary>Show solution</summary>

```python
def get_delivery_offer(bill_amount: float) -> str:
    if bill_amount > 500:
        return "You get a free dessert!"
    return "No free dessert this time."
```

- `if bill_amount > 500:` runs only when the bill is higher than the threshold.
- `return` stops the function and sends back the message.
- The second branch handles all remaining values.

</details>
