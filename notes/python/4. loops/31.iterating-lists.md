# Iterating lists

What to remember

- `for item in list` reads each element in order.
- A Python list can hold mixed types at runtime.
- Type hints are optional and not enforced when the code runs.
- Use list iteration for sequential processing of values.

## Loop over a list

```python
items: list[str | int] = ["aman", "google", 11, 11.5, "slfjslj"]
for item in items:
    print(item)
```

```text
aman
google
11
11.5
slfjslj
```

## Why mixed types still work

Python checks types only when the value is used, not when the list is created.
This makes lists flexible, but a consistent element type is easier to reason about.
