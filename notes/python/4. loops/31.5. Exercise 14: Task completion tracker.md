# Exercise 14: Task completion tracker

## Problem

Build a task completion tracker for a to-do app.

- Define `mark_completed_tasks(tasks)` that accepts a list of task names.
- Iterate through the list using a `for` loop.
- Return a new list where each item is formatted as `"Completed: {task}"`.

## Rules

- Define `mark_completed_tasks(tasks: list[str]) -> list[str]`.
- Build a new list rather than editing the original list in place.
- Prefix each task with `Completed: `.
- Preserve the original task order.
- Return the updated task list.
- Only view the solution after trying your best.
- Include reasoning in the `## Solution` section when it explains the code's design.

```text
['Completed: task one', 'Completed: task two']
```

## Solution

Only view the solution after trying your best.

<details>
<summary>Show solution</summary>

```python
def mark_completed_tasks(tasks: list[str]) -> list[str]:
    completed_tasks: list[str] = []
    for task in tasks:
        completed_tasks.append(f"Completed: {task}")
    return completed_tasks

print(mark_completed_tasks(["task one", "task two"]))
```

Returning a new list keeps the original task list unchanged and makes the function easier to test.

</details>
