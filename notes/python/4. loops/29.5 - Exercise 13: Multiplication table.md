# Ex: 13 - Multiplication table

## Problem

Generate a multiplication table for an educational app feature.

- Define `multiplication_table(number)` that takes a single integer.
- Use a `for` loop and `range()` to generate the table for `number` from 1 to 10.
- Return a list of strings in the format `"number x i = result"`.

## Rules

- Define `multiplication_table(number: int) -> list[str]`.
- Use `range(1, 11)` to generate the 10 rows.
- Return the table instead of printing it directly.
- Keep each result as a single formatted string.
- Preserve the order from 1 to 10.
- Only view the solution after trying your best.

## Expected output

```python
['6 x 1 = 6', '6 x 2 = 12', '6 x 3 = 18', '6 x 4 = 24', '6 x 5 = 30', '6 x 6 = 36', '6 x 7 = 42', '6 x 8 = 48', '6 x 9 = 54', '6 x 10 = 60']
```

## Solution

Only view the solution after trying your best.

<details>
<summary>Show solution</summary>

```python
def multiplication_table(number: int) -> list[str]:
    table: list[str] = []
    for i in range(1, 11):
        table.append(f"{number} x {i} = {number * i}")
    return table

print(multiplication_table(6))
```

A `for` loop with `range()` creates every multiplier, and appending strings keeps the result ordered.

</details>
