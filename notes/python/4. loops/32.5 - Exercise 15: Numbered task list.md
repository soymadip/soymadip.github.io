# Ex: 15 - Numbered task list

## Problem

Build a small helper for a task manager.

- Define `generate_numbered_tasks(tasks)`.
- Use `enumerate()` so numbering starts at `1`.
- Return a list where each item is formatted as `"1. Task Name"`.

## Rules

- Define `generate_numbered_tasks(tasks: list[str]) -> list[str]`.
- Use `enumerate(tasks, start=1)`.
- Preserve the original task order.
- Return a new list of numbered task strings.
- Only view the solution after trying your best.

## Expected output

```text
['1. Clean fridge', '2. Thermostat check']
```

## Solution

Only view the solution after trying your best.

<details>
<summary>Show solution</summary>

```python
def generate_numbered_tasks(tasks: list[str]) -> list[str]:
    task_list: list[str] = []
    for idx, task_name in enumerate(tasks, start=1):
        task_list.append(f"{idx}. {task_name}")
    return task_list

print(generate_numbered_tasks(["Clean fridge", "Thermostat check"]))
```

Using `enumerate(..., start=1)` lets the function create human-friendly task numbers without managing the counter manually.

</details>
