# Ex: 18 - Parcel scanning system

## Problem

Automate a parcel scanning system for a warehouse. Each parcel has a barcode, and the system must validate all parcels and report issues.

- Iterate through each barcode in `parcel_codes`.
- If a barcode is "DAMAGED", skip it with `continue` and log "Skipped damaged parcel".
- If a barcode is "STOP", exit with `break` and log "Critical error: Stopping scan".
- For valid barcodes, log `Scanned parcel: <barcode>`.
- If the entire list is scanned without hitting "STOP", log "All parcels scanned successfully".

## Rules

- Define `scan_parcels(parcel_codes: list[str]) -> list[str]`.
- Use a `for` loop to process each barcode.
- Use `if/elif/else` inside the loop for decision-making.
- Use a `for-else` block to handle a successful full scan.
- Return a list of all scan log messages.
- Only view the solution after trying your best.

## Expected output

```text
['Scanned parcel: ABC', 'Skipped damaged parcel', 'Scanned parcel: XYZ', 'All parcels scanned successfully']
```

```python
def scan_parcels(parcel_codes: list[str]) -> list[str]:
    messages: list[str] = []

    for barcode in parcel_codes:
        if barcode.lower() == "damaged":
            messages.append("Skipped damaged parcel")
            continue
        elif barcode.lower() == "stop":
            messages.append("Critical error: Stopping scan")
            break
        else:
            messages.append(f"Scanned parcel: {barcode}")
    else:
        # Loop finished without "STOP"
        messages.append("All parcels scanned successfully")

    return messages

# Test data
print(scan_parcels(["ABC", "DAMAGED", "XYZ"]))
```

- `continue` skips the damaged parcel but keeps the scanning process active.
- `break` stops the loop immediately upon encountering a critical error.
- `else` handles the scenario where the warehouse successfully scanned everything.
