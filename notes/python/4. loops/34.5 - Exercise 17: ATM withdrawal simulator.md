# Ex: 17 - ATM Withdrawal Simulator

## Problem

Simulate a backend feature for an ATM. Customers can request multiple withdrawals during a session. Handle each request based on the current account balance.

- Use a `while` loop to iterate through the `withdrawals` list.
- If the balance is sufficient, subtract the amount and log `Withdrawn: {amount}`.
- If insufficient, log `Insufficient funds for requested amount: {amount}`.
- After all withdrawals, log "Remaining Balance: {balance}".
- Return a list containing all the generated messages.

## Rules

- Define `simulate_atm_withdrawals(balance: int, withdrawals: list[int]) -> list[str]`.
- Use a `while` loop with a manual index.
- Update the balance correctly after each successful withdrawal.
- Return the full list of log messages.
- Only view the solution after trying your best.

## Expected output

```text
['Withdrawn: 100', 'Insufficient funds for requested amount: 500', 'Withdrawn: 50', 'Remaining Balance: 50']
```

## Solution

Only view the solution after trying your best.

```python
def simulate_atm_withdrawals(balance: int, withdrawals: list[int]) -> list[str]:
    result: list[str] = []
    index: int = 0

    while index < len(withdrawals):
        amount = withdrawals[index]
        if amount <= balance:
            balance -= amount
            result.append(f"Withdrawn: {amount}")
        else:
            result.append(f"Insufficient funds for requested amount: {amount}")
        index += 1
        
    result.append(f"Remaining Balance: {balance}")
    return result

# Test data
print(simulate_atm_withdrawals(200, [100, 500, 50]))
```

Using a manual index with a `while` loop gives you fine-grained control over the iteration, which is useful when you might need to skip or repeat steps based on complex logic.
