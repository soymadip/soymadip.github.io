# Ex: 16 - Student score report

## Problem

Build a report generator that pairs student names with their corresponding marks.

- Define `generate_score_report(names, scores)`.
- Use the `zip()` function to combine two separate lists.
- Return a list where each item is formatted as `"Name scored X marks"`.

## Rules

- Define `generate_score_report(names: list[str], scores: list[int]) -> list[str]`.
- Use `zip(names, scores)` for iteration.
- Preserve the order from both lists.
- Return a new list of report strings.
- Only view the solution after trying your best.

## Expected output

```text
['Hitesh scored 50 marks', 'Sonali scored 70 marks', 'Ali scored 100 marks']
```

## Solution

Only view the solution after trying your best.

<details>
<summary>Show solution</summary>

```python
def generate_score_report(names: list[str], scores: list[int]) -> list[str]:
    report: list[str] = []
    for name, score in zip(names, scores):
        report.append(f"{name} scored {score} marks")
    return report

# Test data
names = ["Hitesh", "Sonali", "Ali"]
scores = [50, 70, 100]
print(generate_score_report(names, scores))
```

Using `zip()` is the most idiomatic way in Python to iterate over multiple collections in parallel. It handles the alignment of items automatically without needing manual index management.
