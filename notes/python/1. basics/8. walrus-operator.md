# The Walrus Operator

Introduced in Python 3.8, the walrus operator (`:=`) allows you to assign a value to a variable **inside** an expression. This can lead to cleaner code by removing the need for separate assignment lines.

## What to Remember

- **Statement:** Performs an action (like `x = 5`) but doesn't return a value.
- **Expression:** Evaluates to a value (like `3 + 3`).
- **Walrus (`:=`):** Assigns a value and returns it at the same time.
- Ideal for reducing redundant function calls or simplifying `while` loop conditions.

## Reducing Redundancy

A common use case is when you need to calculate a value and then immediately check it in an `if` statement.

```python
# Standard way: two lines
remainder = 13 % 5
if remainder:
    print(f"Has remainder: {remainder}")

# Pythonic way: one line
if (rem := 13 % 5):
    print(f"Has remainder: {rem}")
```

```text
Has remainder: 3
Has remainder: 3
```

### Why It's Useful
In the example above, the walrus operator saves a line of code. In more complex scenarios, like fetching an environment variable or reading from a file, it prevents you from having to call an expensive function twice.

## Simplifying While Loops

The walrus operator is perfect for "loop until empty" patterns, which are very common when processing user input or data streams.

```python
# This loop continues as long as the user types something
while (user_input := input("Enter something (empty to stop): ").strip()):
    print(f"You typed: {user_input}")
```

```text
Enter something (empty to stop): hello
You typed: hello
Enter something (empty to stop): 
```

### Direct Comparison
Without the walrus operator, you'd often have to write the `input()` line twice: once before the loop and once at the end of the loop body. The walrus operator keeps the assignment and the check in one place.

:::warning Use with Care
Don't use the walrus operator if it makes the code harder to read. If a line becomes too complex, a standard assignment is usually better.
:::
