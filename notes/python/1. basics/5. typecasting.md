# Typecasting (type Conversion)

Typecasting is simply changing data from one type to another. Python does some of this automatically to keep things running smoothly, but you'll often need to do it yourself when working with mixed data like text and numbers.

## What to Remember

- **Automatic (Implicit):** Python "upgrades" types for you in math (e.g., adding a whole number to a decimal results in a decimal).
- **Manual (Explicit):** Use `int()`, `float()`, or `str()` when you need to force a type change.
- Trying to turn text into a number will crash your program if the text isn't a standard number (like trying to turn "hello" into 5).

## Automatic Conversion (implicit)

When you do math with different types, Python automatically converts the "smaller" type to a "larger" one to make sure no data is lost.

```python
a = 7       # whole number (int)
b = 3.5     # decimal (float)

# Python turns 'a' into a decimal before adding them
c = a + b
print(f"Result: {c} | Type: {type(c).__name__}")
```

```text
Result: 10.5 | Type: float
```

## Manual Conversion (explicit)

Python is strict about mixing text and numbers. It won't let you add them together unless you manually convert them first.

### The Main Casting Functions

- `str()`: Turns anything into text.
- `int()`: Turns text or decimals into a whole number (removes the decimal part).
- `float()`: Turns text or whole numbers into a decimal.

```python
user_input = "15"
base_value = 10

# Anti-pattern: This will crash (can't add string and int)
# total = base_value + user_input

# Pythonic: Manually convert the text to a number first
total = base_value + int(user_input)
print(f"Total: {total}")
```

```text
Total: 25
```

### Avoiding the Valueerror Trap

When converting text to a whole number, the text must look like a standard number.

```python
# This works fine
print(int("42"))

# This crashes because of the decimal point
# print(int("42.5"))

# The safe way: convert to a decimal first, then to a whole number
print(int(float("42.5"))) # Result: 42
```

```text
42
42
```
