# Variables and Data Types

In Python, you don't need to declare a variable's type (like `int` or `char` in C). Python is **dynamically typed**, meaning it figures out the type of data based on the value you assign to it.

## What to Remember

- You don't need to declare types; just use `variable = value`.
- Use `type(variable)` to check what kind of data is stored.
- **Primitive Types** (integers, floats, booleans, strings) store single values.
- **Derived Types** (lists, dicts, sets) store collections of values.
- Python variables are **references** to objects in memory.

## Dynamic Typing Vs. Static Typing

If you are coming from C, you might be used to writing `int a = 5;`. In Python, you just write `a = 5`. You can even change the type of data a variable holds later on, though it's usually better to keep it consistent.

```python
a = 10      # Initially an integer
print(type(a))

a = "Ten"   # Now it's a string
print(type(a))
```

```text
<class 'int'>
<class 'str'>
```

## Primitive vs. Derived Types

Python categorizes data into two main buckets:

### 1. Primitive Data Types
These are the basic building blocks that hold a single value.
- **[Numeric Types](./4.1.%20numeric-types.md):** Integers, Floats, and Complex numbers.
- **[Booleans & None](./4.2.%20booleans-none.md):** Logic (`True`/`False`) and the absence of value (`None`).
- **[Strings](./7. strings.md):** Text and character sequences.

### 2. Derived Data Types (Collections)
These are containers used to organize multiple values.
- **[Lists & Tuples](../2.%20derived-data-types/1.%20lists.md):** Ordered sequences.
- **[Dictionaries](../2.%20derived-data-types/2.%20dictionary.md):** Key-value mappings.
- **[Sets](../2.%20derived-data-types/3.%20sets.md):** Unique unordered collections.
