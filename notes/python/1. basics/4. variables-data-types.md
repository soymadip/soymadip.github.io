# Variables and Data Types

In Python, you don't need to declare a variable's type (like `int` or `char` in C). Python is **dynamically typed**, meaning it figures out the type of data based on the value you assign to it.

## What to Remember

- You don't need to declare types; just use `variable = value`.
- Use `type(variable)` to check what kind of data is stored.
- **Integers** are whole numbers, **Floats** are decimals.
- **Booleans** are `True` or `False` (capitalization matters!).
- Lists and Tuples are for ordered collections of data.

## Dynamic Typing Vs. Static Typing

If you are coming from C, you might be used to writing `int a = 5;`. In Python, you just write `a = 5`. You can even change the type of data a variable holds later on, though it's usually better to keep it consistent.

```python
a = 10      # Initially an integer
print(type(a))

a = "Ten"   # Now it's a string
print(type(a))
```

```text
<class 'int'>
<class 'str'>
```

## Basic Numeric Types

Python handles numbers very simply. You mostly work with Integers and Floats.

```python
age = 25          # Integer (int)
price = 19.99     # Decimal (float)

# Complex numbers use 'j' for the imaginary part
coordinate = 3 + 5j 

print(age, price, coordinate)
```

```text
25 19.99 (3+5j)
```

## Text and Logic

Text is stored as a **String**, and logic is handled by **Booleans**.

```python
name = "Alice"    # String (str)
is_active = True  # Boolean (bool)

print(name, is_active)
```

```text
Alice True
```

## Collections of Data

When you need to store more than one value, you use a collection.

### Lists (mutable)
A list is an ordered group of items that you **can** change later.

```python
# A list can even hold different types of data
my_list = [1, "apple", 3.5]
my_list[0] = 10  # You can change items

print(my_list)
```

```text
[10, 'apple', 3.5]
```

### Tuples (immutable)
A tuple is like a list, but you **cannot** change it once it is created. It is useful for data that should stay constant.

```python
# Defined with parentheses
my_tuple = ("parrot", "sparrow")
# my_tuple[0] = "eagle"  # This would cause an error

print(my_tuple)
```

```text
('parrot', 'sparrow')
```
