# Booleans & None

Logic in Python is handled by two main objects: `True` and `False`. There's also a special object called `None` which represents the absence of a value.

## What to Remember

- **Booleans (`bool`):** Capitalization is mandatory (`True`, `False`).
- **NoneType (`None`):** Represents "nothing" or "empty".
- Use `is` to check for `None` instead of `==`.
- Everything in Python has a "truthiness" value.

## Booleans

Booleans are often the result of comparisons.

```python
x = 10
y = 20

# Boolean expressions
is_greater = x > y
is_equal = x == 10

print(is_greater, is_equal)
```

```text
False True
```

### Truthiness

Every object in Python can be evaluated in a boolean context. For example, empty containers (lists, strings) and the number `0` are "Falsy".

```python
# Falsy values
print(bool(0))        # False
print(bool(""))       # False
print(bool([]))       # False

# Truthy values
print(bool(1))        # True
print(bool("Hello"))  # True
print(bool([1, 2]))   # True
```

```text
False
False
False
True
True
True
```

## The None Object

`None` is its own type (`NoneType`). It is not the same as `0`, `False`, or an empty string.

```python
# Used as a placeholder or to signify no return value
status = None

if status is None:
    print("Status is not set yet.")
```

```text
Status is not set yet.
```

### Why use `is None`?
Always use the identity operator `is` when checking for `None`. This is faster and safer than `==` because there is only ever one instance of `None` in memory.

```python
x = None
# Preferred
print(x is None)

# Discouraged (but works)
print(x == None)
```

```text
True
True
```
