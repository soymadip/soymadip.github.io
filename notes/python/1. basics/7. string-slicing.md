# String Slicing & Operations

In Python, strings are fixed pieces of text that act like arrays. Because they are arrays, you can grab characters by their position (index), cut them into slices, or loop through them directly.

## What to Remember

- Use `len(string)` to find the total number of characters.
- Strings are **0-indexed** (start at 0). Use `-1` to grab the last character.
- Slicing uses the `[start:stop:step]` format. The `stop` position is **not included**.
- Strings cannot be changed once created (they are immutable).

## String Length

In Python, we use the built-in `len()` function to find the length of a string.

```python
fruit = "Mango"
print(len(fruit))  # Result: 5
```

```text
5
```

## Slicing Syntax

Slicing is the easiest way to cut out a part of a string without using loops. Remember that the "stop" number is exclusive (it stops *before* that index).

```python
pie = "ApplePie"

# Basic slicing: [start:stop]
print(pie[2:6])     # 'pleP' (starts at 2, stops before 6)

# Shortcuts
print(pie[:5])      # 'Apple' (omitting start defaults to 0)
print(pie[5:])      # 'Pie' (omitting stop goes to the end)
print(pie[-3:])     # 'Pie' (counting from the end)
```

```text
pleP
Apple
Pie
Pie
```


## Splitting Strings

Use `.split()` to break a long string into a list of smaller strings based on a separator (like a dash or space).

### Anti-pattern: Multiple Splits
If you need several parts of a string, don't split it multiple times. It makes the computer do the same work twice.

```python
# Anti-pattern: Inefficient
name = "google-12".split('-')[0]
age = "google-12".split('-')[1]

print(name, age)
```

```text
google 12
```

### Pythonic: Unpacking
Since `.split()` returns a list, you can "unpack" the parts directly into variables in one go.

```python
# Pythonic: Split once and assign both variables
name, age_str = "google-12".split('-')
age = int(age_str)

print(name, age)
```

```text
google 12
```

## Direct Iteration

Don't use an index counter to look at every character. Python can loop through the string array directly.

```python
# The clean way to look at every character
for char in "ABC":
    print(char)
```

```text
A
B
C
```
