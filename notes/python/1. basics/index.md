The **Basics** section is designed for those who have some programming experience (like in C) but need to understand how Python specifically handles foundations.

This section covers:
- **Symbols Reference:** Quick guide to common Python symbols.
- **Escape Sequences:** Reference for `\n`, `\t`, and other special characters.
- **Arithmetic Operators:** Standard math, floor division, and exponentiation.
- **Variables & Data Types:** Python's dynamic typing and high-level overview of types.
- **[Numeric Types](./4.1.%20numeric-types.md):** Integers, Floats, and Complex numbers.
- **[Booleans & None](./4.2.%20booleans-none.md):** Logic and special values.
- **Typecasting:** Explicit and implicit conversion between data types.
- **User Input:** Interacting with users through the terminal.
- **Strings:** Immutability, common methods, and slicing.
- **Walrus Operator:** Using assignment expressions (`:=`) to simplify logic.

These topics provide the necessary foundation before moving into conditional logic and loops.
