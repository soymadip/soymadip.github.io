# Escape Sequence Characters

Escape sequence characters are special characters that you can use inside strings to perform actions like adding a new line or a tab.

## What to remember

- **New Line (`\n`):** Moves the text following it to a new line.
- **Tab (`\t`):** Adds a horizontal tab (usually 4 spaces) to the text.
- **Backslash (`\\`):** Allows you to include a literal backslash in your string.
- **Single/Double Quote (`\'` or `\"`):** Lets you include quotes within a string of the same type.

## Common Escape Sequences

```python
# New Line example
print("Hello\nWorld")

# Tab example
print("Item 1\tItem 2\tItem 3")

# Quote example
print('It\'s a beautiful day!')
```

```text
Hello
World
Item 1	Item 2	Item 3
It's a beautiful day!
```

## Why they are useful

Escape sequences are especially helpful when you need to format long strings or include characters that normally have a special meaning in Python code.
