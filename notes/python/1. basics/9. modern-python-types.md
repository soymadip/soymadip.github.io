# Modern Python Types

While Python is dynamically typed, modern Python (3.5+) uses **type hints** to make code more readable and to allow tools like `mypy` or IDEs (VS Code, PyCharm) to catch bugs before you even run your code.

## What to remember

- **Static Analysis:** Type hints are for _developers_ and _tools_, not for the Python interpreter. They don't affect runtime performance.
- **Improved Readability:** Explicit types act as built-in documentation, telling you exactly what a function expects and returns.
- **Modern Syntax:** Python 3.10+ uses the `|` operator for Union types (e.g., `int | str`) instead of the older `Union[int, str]`.
- **Collections:** You can specify the types _inside_ a list or dictionary using brackets (e.g., `list[str]`).

## Basic Type Hints

You can add type hints to variables and function parameters using a colon (`:`) and to return values using an arrow (`->`).

```python
# Variable hints
age: int = 25
name: str = "Alice"
is_admin: bool = False

# Function hints
def greet(user: str) -> str:
    return f"Hello, {user}!"

print(greet("Aman"))
```

**Output:**

```text
Hello, Aman!
```

## Hinting Collections

For lists, dictionaries, and tuples, you can specify the type of the elements they contain.

```python
# A list of integers
scores: list[int] = [80, 90, 75]

# A dictionary mapping strings to integers
prices: dict[str, float] = {"apple": 0.5, "banana": 0.3}

# A tuple with fixed types
coordinate: tuple[float, float] = (12.5, 45.0)

print(scores)
print(prices)
```

**Output:**

```text
[80, 90, 75]
{'apple': 0.5, 'banana': 0.3}
```

## Union and Optional Types

Sometimes a value could be one of several types, or it might be `None`.

### Union (Multiple Types)

Use the `|` operator to say "this or that."

```python
def process_data(data: int | str) -> None:
    print(f"Processing: {data}")

process_data(10)
process_data("Login")
```

**Output:**

```text
Processing: 10
Processing: Login
```

### Optional (Type or None)

If a variable can be a specific type or `None`, use `| None`.

```python
def find_user(user_id: int) -> str | None:
    if user_id == 1:
        return "Admin"
    return None

print(find_user(1))
print(find_user(99))
```

**Output:**

```text
Admin
None
```

## Why use Type Hints?

1.  **Catching Bugs Early:** If you try to pass a string to a function that expects an `int`, your IDE will highlight the error immediately.
2.  **Better Autocomplete:** Your editor will know exactly which methods are available for a variable based on its type hint.
3.  **Self-Documenting Code:** Other developers (and your future self) won't have to guess what `data` or `config` is supposed to be.

:::tip Runtime Enforcement
Remember that Python will _not_ stop your code from running if you ignore type hints. To actually enforce them, you should use a tool like `mypy` as part of your testing workflow.
:::
