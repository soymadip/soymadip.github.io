# Modern Python Types

While Python is dynamically typed, modern Python (3.5+) uses **type hints** to make code more readable and to allow tools like `mypy` or IDEs to catch bugs before runtime. They act as built-in documentation that explains the "What" and "Why" of your data structures.

## What to Remember

- **Static Analysis:** Type hints are for _developers_ and _tools_ (like VS Code or `mypy`), not for the Python interpreter.
- **Runtime Performance:** They do not slow down your code; Python ignores them during execution.
- **Modern Syntax:** Python 3.10+ uses the `|` operator for Union types (e.g., `int | str`) and `None` (e.g., `str | None`).
- **Built-in Collections:** Since Python 3.9, you can use `list[]`, `dict[]`, and `set[]` directly for hinting without extra imports.

## Why Use Type Hints?

1.  **Catching Bugs Early:** Your IDE highlights type mismatches immediately, preventing common runtime errors.
2.  **Better Autocomplete:** Your editor suggests the exact methods available for a variable (e.g., string methods for a `str` hint).
3.  **Self-Documenting Code:** Other developers (and your future self) don't have to guess what a complex dictionary or list is supposed to contain.

:::tip Runtime Enforcement
Remember that Python will _not_ stop your code from running if you ignore type hints. To actually enforce them, you should use a tool like `mypy` as part of your testing workflow.
:::

## Basic Type Hints

You can hint variables and function parameters using a colon (`:`) and return values using an arrow (`->`).

```python
def greet(user: str) -> str:
    return f"Hello, {user}!"

print(greet("Aman"))
```

**Output:**

```text
Hello, Aman!
```

## Hinting Collections

For collections, specify the type of elements inside square brackets `[]`.

### Lists and Sets

These hold elements of a specific type.

```python
scores: list[int] = [80, 90, 75]
tags: set[str] = {"python", "coding", "tips"}

print(f"Scores: {scores}")
# Sets are unordered; we sort for consistent output
print(f"Tags: {sorted(list(tags))}")
```

**Output:**

```text
Scores: [80, 90, 75]
Tags: ['coding', 'python', 'tips']
```

### Dictionaries

Dictionaries require two types: `dict[KeyType, ValueType]`.

```python
prices: dict[str, float] = {"apple": 0.5, "banana": 0.3}
print(prices["apple"])
```

**Output:**

```text
0.5
```

### Tuples

Tuples can have fixed types for each position, or use `...` for variable length.

```python
coordinate: tuple[float, float] = (12.5, 45.0)
numbers: tuple[int, ...] = (1, 2, 3)

print(coordinate)
```

**Output:**

```text
(12.5, 45.0)
```

## Nested Structures

You can nest hints to describe complex data like API responses.

```python
# A list of dictionaries with mixed values
users: list[dict[str, str | int]] = [
    {"name": "Aman", "age": 25},
    {"name": "Sonia", "age": 22}
]

def get_user_names(user_list: list[dict[str, str | int]]) -> list[str]:
    return [user["name"] for user in user_list]

print(get_user_names(users))
```

**Output:**

```text
['Aman', 'Sonia']
```

## Union and Optional Types

Use the `|` operator (Python 3.10+) to allow multiple types or handle `None`.

```python
def process_data(data: int | str) -> None:
    print(f"Processing: {data}")

def find_user(user_id: int) -> str | None:
    if user_id == 1:
        return "Admin"
    return None

process_data(10)
print(find_user(1))
print(find_user(99))
```

**Output:**

```text
Processing: 10
Admin
None
```
