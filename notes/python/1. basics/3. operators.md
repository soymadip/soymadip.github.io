# Arithmetic Operators

Python provides the standard math operators you are familiar with, plus a few others that make common calculations much faster.

## What to remember

- **Standard Division (`/`):** In Python, division *always* results in a float, even if the result is a whole number (e.g., `10 / 2` = `5.0`).
- **Floor Division (`//`):** This divides and then chops off the decimal, leaving just the whole number.
- **Exponentiation (`**`):** Use this instead of `pow()` to raise a number to a power.
- **Modulo (`%`):** This gives you the remainder of a division.

## Basic Arithmetic

Python behaves like a calculator. It follows the standard order of operations (PEMDAS).

```python
a = 15
b = 7

print(a + b)   # Addition (22)
print(a - b)   # Subtraction (8)
print(a * b)   # Multiplication (105)
```

## Unique Python Operators

If you're coming from C, you'll find these very handy for quick math.

### Floor Division vs Standard Division
Use `//` when you don't care about the decimal remainder.

```python
print(15 / 7)    # 2.1428... (Standard)
print(15 // 7)   # 2 (Floor)
```

### Exponentiation
Raising one number to the power of another is built directly into the language.

```python
print(5 ** 3)    # 125 (5 to the power of 3)
```

## Shorthand Operators

You can modify a variable's value in place using shorthand.

```python
counter = 10
counter += 5     # Same as counter = counter + 5
counter -= 2     # Same as counter = counter - 2
print(counter)   # Result: 13
```
