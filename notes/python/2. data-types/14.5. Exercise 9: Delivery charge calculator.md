# Delivery charge calculator

What to remember

- Use `if` / `elif` / `else` to map ranges to a single result.
- Check the smallest range first to avoid overlapping conditions.
- Return exact strings when the output is evaluated by tests.
- Use `<=` and `>` consistently to cover all boundaries.

## Tiered Distance Checks

Each condition covers a distance range and returns one message.

```python
def calculate_delivery_charge(distance: float) -> str:
    if distance <= 2:
        return "Delivery charge: 0"
    elif distance <= 5:
        return "Delivery charge: 30"
    elif distance <= 10:
        return "Delivery charge: 50"
    return "Delivery not available for your location."
```

```python
print(calculate_delivery_charge(3))
print(calculate_delivery_charge(11))
```

## Why Order Matters

- The first true branch wins.
- Narrow ranges should come before wider defaults.
- A final `else` or bare return handles any remaining case.

## Boundary Testing

:::warning
Range boundaries are a common source of off-by-one errors. The checks `<= 2`, `<= 5`, and `<= 10` partition the distances cleanly.
:::

```text
Delivery charge: 30
Delivery not available for your location.
```

:::tip
Write a quick table of input/output pairs when you test range logic: it helps catch off-by-one gaps.
:::
