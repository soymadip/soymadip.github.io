# Lists

Lists are the most common collection in Python. They are ordered, mutable (changeable), and can store elements of different types simultaneously.

## What to remember

- Lists are **mutable**—you can change, add, or remove items after creation.
- They maintain **insertion order**.
- Use `append()` to add to the end and `pop()` to remove from the end.
- Python does not enforce element types at runtime, even with hints.

## Basic Operations

If you're coming from C, think of a list as a dynamic array that handles resizing for you.

```python
# Type hinting: specify the element type(s) inside list[]
# See: Modern Python Types for details
tech_stack: list[str | float] = ["Python", 3.12, "Bash"]

# Adding items to the end
tech_stack.append("C")

# Removing and returning the last item
last_added = tech_stack.pop()

print(tech_stack)
print(f"Removed: {last_added}")
```

**Output:**
```text
['Python', 3.12, 'Bash']
Removed: C
```

## Iteration

You can loop through a list directly. This is the "Pythonic" way compared to using index-based counters.

```python
ingredients = ["ginger", "cardamom", "cloves"]

for spice in ingredients:
    print(f"Adding {spice}...")
```

**Output:**
```text
Adding ginger...
Adding cardamom...
Adding cloves...
```

## Worth Mentioning: Useful Methods

- `insert(index, item)`: Adds an item at a specific position.
- `remove(item)`: Removes the first occurrence of a value.
- `extend(collection)`: Appends all items from another collection.
- `sort()`: Sorts the list in place.
