# Ex: 20 - Loyalty points tracker

## Problem

Build a loyalty points tracker for a retail chain that rewards customers based on their spending. The tracker calculates total transaction amounts and awards points.

- Define a global variable `loyalty_points` to track points across all customers.
- Create `process_transactions(transactions: list[int]) -> int`:
    - Initialize a local variable `total` for the customer's sum.
    - Define a nested function `apply_bonus()`:
        - If the `total` > ₹1000, add a bonus of ₹50.
        - Use `nonlocal` to modify the `total`.
    - Update the global `loyalty_points` (1 point for every ₹100 spent).
    - Return the final `total`.

## Rules

- Use `nonlocal` to update the transaction total within the nested function.
- Use `global` to update the points tracker from inside the function.
- Points are calculated using floor division (`total // 100`).
- Only view the solution after trying your best.

## Expected output

```text
# process_transactions([400, 700])
1150
```

## Solution

Only view the solution after trying your best.

<summary>Show solution</summary>

```python
loyalty_points: int = 0

def process_transactions(transactions: list[int]) -> int:
    total = sum(transactions)

    def apply_bonus():
        # Update the parent function's variable
        nonlocal total
        if total > 1000:
            total += 50

    apply_bonus()

    # Update the global points tracker
    global loyalty_points
    loyalty_points += total // 100

    return total

# Test
print(process_transactions([400, 700]))
```

- `nonlocal` is essential here to change the `total` defined in the outer `process_transactions` function.
- `global` is used because `loyalty_points` is shared across all function calls at the module level.
