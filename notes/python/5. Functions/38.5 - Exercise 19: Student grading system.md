# Ex: 19 - Student grading system

## Problem

Build an academic grading system that calculates a student's grade based on their score and generates a formatted report.

- Define `calculate_grade(score: int | float) -> str` to return:
    - "A" for score ≥ 90
    - "B" for ≥ 75
    - "C" for ≥ 60
    - "D" for ≥ 40
    - "F" otherwise
- Define `generate_student_report(name: str, score: int | float) -> str` that:
    - Calls `calculate_grade` to determine the grade.
    - Returns a string like: `"Aman has scored 80 and received grade B"`

## Rules

- Use `if/elif/else` inside the grading function.
- Use string formatting for the final report.
- Ensure names are properly capitalized in the final report.
- Only view the solution after trying your best.

## Expected output

```text
Aman has scored 80 and received grade B
```

## Solution

Only view the solution after trying your best.

<details>
<summary>Show solution</summary>

```python
def calculate_grade(score: int | float) -> str:
    if score >= 90:
        return "A"
    elif score >= 75:
        return "B"
    elif score >= 60:
        return "C"
    elif score >= 40:
        return "D"
    else:
        return "F"

def generate_student_report(name: str, score: int | float) -> str:
    # Capitalize name and call the grade function
    grade = calculate_grade(score)
    return f"{name.title()} has scored {score} and received grade {grade}"

# Test
print(generate_student_report("aman", 80))
```

- Nested function calls allow you to separate the grading logic from the reporting logic.
- `.title()` ensures the student's name is always correctly capitalized.
