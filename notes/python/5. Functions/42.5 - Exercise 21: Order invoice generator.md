# Ex: 21 - Order invoice generator

## Problem

Build an automated restaurant invoice system that generates a detailed report for customers.

- Define `generate_invoice(customer_name="Guest", *items, **charges) -> str`:
    - `customer_name`: The name of the customer (defaults to `"Guest"`).
    - `items`: An arbitrary number of ordered food items.
    - `**charges`: Dynamic extra charges like `tax`, `service`, `delivery`.
- The function should return a single string with:
    - **Header**: `Invoice for <customer_name>:`
    - **Items Section**: A list of all items (if any).
    - **Charges Section**: A list of all charges with capitalized names (if any).
    - **Total Amount**: The sum of all charges.

## Rules

- Sum only the values from `**charges` for the total.
- Charge names should be capitalized (e.g., `tax` becomes `Tax`).
- Use `\n` to join all lines into a single string.
- Only view the solution after trying your best.

## Expected output

```text
Invoice for Amit:
Items:
- Burger
- Fries
Charges:
Tax: 50.0
Service: 20.0
Total Amount Due: ₹70.0
```

```python
def generate_invoice(customer_name: str = "Guest", *items: str, **charges: float) -> str:
    lines = [f"Invoice for {customer_name}:"]

    # Add items if they exist
    if items:
        lines.append("Items:")
        for item in items:
            lines.append(f"- {item}")

    # Add charges if they exist
    if charges:
        lines.append("Charges:")
        for name, amount in charges.items():
            lines.append(f"{name.capitalize()}: {amount}")

    # Calculate and add total
    total = sum(charges.values())
    lines.append(f"Total Amount Due: ₹{total}")

    return "\n".join(lines)

# Test Example
print(generate_invoice("Amit", "Burger", "Fries", tax=50.0, service=20.0))
```

- `*items` allows you to pass as many food items as needed as positional arguments.
- `**charges` allows you to define arbitrary cost types as keyword arguments.
- Summing `charges.values()` is a direct way to calculate the final price.
