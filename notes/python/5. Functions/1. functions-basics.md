# Functions and Scope

Functions are the building blocks of reusable code. In Python, understanding how variables are resolved (Scope) and how arguments are passed is key to writing clean, maintainable logic.

## What to remember

- **Scope (LEGB):** Python looks for variables in order: **Local** → **Enclosing** → **Global** → **Built-in**.
- **Mutable Default Trap:** Never use mutable objects (like `[]`) as default arguments. Use `None` instead.
- **Flexible Arguments:** `*args` collects extra positional arguments into a **tuple**, while `**kwargs` collects keyword arguments into a **dictionary**.
- **Global vs Nonlocal:** Use `global` to modify top-level variables and `nonlocal` to modify variables in a parent function.

## The LEGB Scope Rule

If you're coming from C, Python's scope rules might feel broader. The interpreter searches four levels to find a variable name.

```python
x = "Global"

def outer():
    x = "Enclosing"
    
    def inner():
        x = "Local"
        print(f"Inner: {x}") # Prints "Local"
    
    inner()
    print(f"Outer: {x}") # Prints "Enclosing"

outer()
print(f"Global: {x}") # Prints "Global"
```

**Output:**
```text
Inner: Local
Outer: Enclosing
Global: Global
```

### Modifying Outside Variables
By default, you can *read* global variables inside a function, but you cannot *modify* them unless you explicitly declare them.

```python
count = 0

def increment():
    global count  # Tells Python to use the top-level 'count'
    count += 1

increment()
print(f"Global count: {count}")

def parent():
    name = "Alice"
    def child():
        nonlocal name  # Targets the variable in 'parent' scope
        name = "Bob"
    child()
    print(f"Parent name: {name}")

parent()
```

**Output:**
```text
Global count: 1
Parent name: Bob
```

## Advanced Argument Patterns

Python offers powerful ways to handle functions that take a varying number of inputs.

### *args and **kwargs

- `*args`: Allows a function to take any number of positional arguments (collected as a **tuple**).
- `**kwargs`: Allows a function to take any number of keyword arguments (collected as a **dictionary**).

```python
def build_profile(name, *skills, **details):
    print(f"Name: {name}")
    print(f"Skills (tuple): {skills}")
    print(f"Details (dict): {details}")

build_profile("Aman", "Python", "C", location="India", role="Dev")
```

**Output:**
```text
Name: Aman
Skills (tuple): ('Python', 'C')
Details (dict): {'location': 'India', 'role': 'Dev'}
```

## The Mutable Default Trap

A common "gotcha" for intermediate developers is using a list or dictionary as a default argument. These are created **once** when the function is defined, not every time it's called.

```python
# Anti-pattern: The same list is shared across all calls!
def add_item(item, basket=[]):
    basket.append(item)
    return basket

print(add_item("Apple"))
print(add_item("Banana")) # Oops! Shared list

# Pythonic: Use None as a placeholder
def add_item_safe(item, basket=None):
    if basket is None:
        basket = []
    basket.append(item)
    return basket

print(add_item_safe("Apple"))
print(add_item_safe("Banana")) # New list each time
```

**Output:**
```text
['Apple']
['Apple', 'Banana']
['Apple']
['Banana']
```

## Worth Mentioning: Functional Programming Tools

For simple operations, Python offers tools that can make your code more concise.

- **Lambda Functions:** Anonymous, single-expression functions.
- **map():** Applies a function to all items in a collection.
- **filter():** Keeps only items in a collection that meet a criteria.

```python
# Lambda: a quick square function
square = lambda x: x ** 2
print(square(5))

# map: convert a list of strings to integers
nums = ["1", "2", "3"]
print(list(map(int, nums)))

# filter: keep only numbers greater than 10
data = [5, 12, 8, 20]
print(list(filter(lambda x: x > 10, data)))
```

**Output:**
```text
25
[1, 2, 3]
[12, 20]
```
