# Lambda Functions

Lambdas are small, anonymous functions defined without a name using the `lambda` keyword.  
They are ideal for quick, one-time-use operations that don't need a heavy formal `def`.

**Syntax:** `lambda arguments : expression`

```python
# Simple lambda for doubling
double = lambda x: x * 2
print(double(5)) # 10

# Lambda for full name
full_name = lambda fst, lst: fst + " " + lst
print(full_name("Soymadip", "Das"))

# Usage with conditionals
max_val = lambda a, b: a if a > b else b
print(max_val(10, 18)) # 18
```

**Output:**

```text
10
Soymadip Das
18
```

:::tip Use Case
Lambdas are most powerful when used inside Higher-Order Functions like `map()` and `filter()`, where we need a quick function as an argument.
:::
