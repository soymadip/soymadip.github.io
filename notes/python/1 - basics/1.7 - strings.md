# Strings

Strings in Python are sequences of characters used to store text. They are one of the most versatile primitive types.

## What to Remember

- Strings are **immutable**—you cannot change a character in place.
- They are **0-indexed** (start at 0).
- Use `len(string)` to find the total number of characters.
- Slicing uses the `[start:stop:step]` format.

## Creating Strings

You can use single or double quotes for strings. Triple quotes are used for multi-line strings.

```python
name = "Alice"
greeting = 'Hello'
multi_line = """This is a
long string."""

print(name, greeting)
```

```text
Alice Hello
```

## Immutability

If you're coming from C, you might be used to changing an array in place. In Python, you can't do that. You have to create a _new_ string.

```python
fruit = "Apple"
# fruit[0] = "B"  # This would cause a TypeError

# Instead, create a new one
new_fruit = "B" + fruit[1:]
print(new_fruit)
```

```text
Bpple
```

## Common String Methods

Python has hundreds of built-in methods for strings. Here are the most common ones.

```python
text = "  Python is fun!  "

print(text.lower())      # lowercase
print(text.upper())      # uppercase
print(text.strip())      # Remove whitespace from ends
print(text.replace("fun", "powerful"))
```

```text
  python is fun!
  PYTHON IS FUN!
Python is fun!
  Python is powerful!
```

## Slicing Syntax

Slicing is the easiest way to cut out a part of a string. Remember that the "stop" number is exclusive (it stops _before_ that index).

```python
pie = "ApplePie"

# Basic slicing: [start:stop]
print(pie[2:6])     # 'pleP' (starts at 2, stops before 6)

# Shortcuts
print(pie[:5])      # 'Apple' (omitting start defaults to 0)
print(pie[5:])      # 'Pie' (omitting stop goes to the end)
print(pie[-3:])     # 'Pie' (counting from the end)
```

```text
pleP
Apple
Pie
Pie
```

## Splitting and Unpacking

Use `.split()` to break a string into a list. Instead of splitting multiple times, use **unpacking** to assign parts directly to variables.

```python
# Pythonic: Split once and assign both variables
name, age_str = "google-12".split('-')
age = int(age_str)

print(name, age)
```

```text
google 12
```

## Direct Iteration

Don't use an index counter to look at every character. Python can loop through the string array directly.

```python
# The clean way to look at every character
for char in "ABC":
    print(char)
```

```text
A
B
C
```
