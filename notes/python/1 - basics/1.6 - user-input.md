# Taking User Input

Python makes it very easy to interact with the user through the `input()` function. You can pass a string directly to `input()` to show a message to the user before they type.

## Basic Input

The `input()` function returns a string by default, even if the user types a number.

```python
name = input("Enter your name: ")
print(f"Hello, {name}!")
```

```text
Enter your name: Alice
Hello, Alice!
```

## Handling Numeric Input

Since `input()` always returns text, manual typecasting is necessary if you need to perform arithmetic with the result.

```python
# Anti-pattern: This will crash if you try to add 10 to a string
# age = input("Enter your age: ")
# print(age + 10)

# Pythonic: Cast the input immediately
age = int(input("Enter your age: "))
print(f"Next year you will be {age + 1}!")
```

```text
Enter your age: 25
Next year you will be 26!
```

:::warning Input Validation
If a user types something that isn't a valid number (like "apple") when you expect an integer, Python will throw a `ValueError`. Always ensure the input matches the expected type before casting.
:::
