# Taking User Input

Python makes it very easy to interact with the user through the `input()` function.

## What to Remember

- **Input is always text:** The `input()` function returns a string by default, even if the user types a number.
- **Typecasting is necessary:** If you need to do math with a user's input, you must convert it to an `int` or `float` first.
- **Display prompts:** You can pass a string directly to `input()` to show a message to the user before they type.

## Basic Input

```python
name = input("Enter your name: ")
print(f"Hello, {name}!")
```

```text
Enter your name: Alice
Hello, Alice!
```

## Handling Numeric Input

Since `input()` always returns a string, you have to wrap it in a casting function like `int()` to perform arithmetic.

```python
# Anti-pattern: This will crash if you try to add 10 to a string
# age = input("Enter your age: ")
# print(age + 10)

# Pythonic: Cast the input immediately
age = int(input("Enter your age: "))
print(f"Next year you will be {age + 1}!")
```

```text
Enter your age: 25
Next year you will be 26!
```

## Error Handling Tip

If you try to turn something into an integer that isn't a number (like the word "apple"), Python will throw a `ValueError`. Always make sure you're expecting the right kind of input from your users.
