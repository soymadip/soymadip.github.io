# Return Values

The `return` statement is used to send a result back from a function to the caller. In Python, it also acts as a "stop" button—once a function hits a return, it finishes executing immediately.

## What to Remember

- **Early Exit:** You can use `return` inside a conditional to "short-circuit" a function.
- **Multiple Values:** Python can return multiple values separated by commas. These are automatically packed into a **tuple**.
- **Unpacking:** You can unpack returned tuples into separate variables. Use `_` to ignore values you don't need.

## Early Exit (Short-Circuiting)

Functions often use early returns to handle special cases or errors before running the main logic. This makes the code cleaner by avoiding deep indentation.

```python
def chai_status(cups: int = 0):
    if cups == 0:
        return "Sorry, chai over"  # Early exit

    return "Chai is ready"
    print("This will never be printed")

print(chai_status(0))
print(chai_status(5))
```

**Output:**

```text
Sorry, chai over
Chai is ready
```

## Returning Multiple Values

When you return multiple items, Python wraps them in a single tuple. This is a very powerful feature for returning multi-dimensional data without needing complex objects.

```python
def chai_report():
    return 100, 20  # (sold, remaining)

sold, remains = chai_report()
print(f"Sold: {sold}, Remaining: {remains}")
```

**Output:**

```text
Sold: 100, Remaining: 20
```

### Unpacking Pitfalls

If you try to unpack a tuple into fewer variables than it contains, Python will raise a `ValueError`. Use the underscore `_` to throw away values you don't care about during unpacking.

```python
def chai_report_long():
    return 100, 20, 10 # (sold, remaining, waste)

# Handle it by ignoring the last value
sold, remains, _ = chai_report_long()
```
